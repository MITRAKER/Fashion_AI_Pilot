SS27 / Creative studio

Creative studio P1 · feature flag

The user explicitly chooses a mode before anything is generated, and every output is labeled by mode. A beautiful image is never mistaken for a production flat. (CRE-002, SKT-001, SKT-002)

Mood sketch

Loose exploration for atmosphere and direction. Garments, setting, color, and textile references all pull from the same structured brief, not unrelated images.

Never enters the tech pack

Presentation sketch

Polished illustration for proportion, flow, and styling. The designer keeps, replaces, annotates, or regenerates any single asset without redoing the board.

Never labeled as a technical flat

Technical flat

Front and back orthographic views. Any construction detail the model cannot verify is labeled unresolved and routed to the technical designer.

Still requires technical verification
